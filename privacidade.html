TRANSPARÊNCIA E CUIDADO

Aviso de Privacidade

Entenda como o protótipo demonstra o tratamento de informações.

1. Quais dados são solicitados?

Para a demonstração de cadastro, são solicitados nome, e-mail, telefone e senha fictícios. Pedidos podem registrar itens, unidade, valores, forma de pagamento simulada e status.

2. Para que os dados são utilizados?

Os dados permitem simular acesso à conta, identificação do pedido, acompanhamento, histórico e programa de fidelidade.

3. Onde ficam armazenados?

Nesta versão acadêmica, as informações ficam no armazenamento local (localStorage) do navegador utilizado. Não há servidor ou banco de dados conectado.

4. Compartilhamento e pagamentos

O protótipo não envia dados a empresas de pagamento e não realiza cobranças. Não informe senhas reais, dados bancários ou informações pessoais verdadeiras.

5. Cuidados e limitações

O armazenamento local não oferece segurança adequada para uma aplicação comercial. Uma versão real precisaria de servidor, controle de acesso, proteção de senhas, política de retenção e medidas técnicas e organizacionais apropriadas.

6. Seus controles

Como demonstração, você pode limpar os dados do site nas configurações do navegador para remover os registros locais. Isso também apagará cadastros, pedidos e pontos de teste.

Este texto é uma explicação acadêmica do protótipo, não substitui uma política jurídica revisada para operação comercial nem representa certificação de conformidade com a LGPD.
